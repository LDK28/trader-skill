# Вход скринера

`{as_of,companies:[...],spec:{basis,rules,rank,missing:"fail",top?}}`.

`basis` явно задаёт `standard`, `scope`, `period_type`, при необходимости другие поля строки аналитика. Несовместимые базы не смешиваются. Каждая строка: `{uid,class_code,ticker?,as_of,published_at,standard,scope,period_type,metrics,availability}`.

Для отчётности это, например, `IFRS/consolidated/half_year`. Для отдельно нормализованных рыночных показателей допустима явно отличная база `MARKET/instrument/snapshot`; это не превращает их в отчётные факты МСФО. Если критерий требует одного отчётного периода у всех компаний, включи `period_start` и `period_end` в `basis`. Иначе сравниваются последние предоставленные периоды выбранного типа, а их даты сохраняются в результате.

`metrics[name]={value,unit,currency?,published_at?,as_of?}`. При отсутствии времени метрики используются соответствующие времена строки. Даты должны быть не позже `as_of`. Численные значения — десятичные строки; текстовые — строки с unit=`text`. Допустимые единицы: `money`, `money_per_share`, `percent`, `ratio`, `count`, `text`.

`availability={uid,class_code,as_of,api_trade_available:true,account_available:true,cash_eligible:true}`. Эти флаги должны быть подготовлены проверяющим слоем по фактическим данным; скринер проверяет согласованность входа, а не заново связывается с брокером. Он не моделирует историческую доступность из текущего каталога.

Правило: `{metric,unit,currency?,op,value}`. Операторы `> >= < <= == != between in not in`; `between` требует две упорядоченные границы, членство — непустой массив. Для денежных единиц валюта правила обязательна. `rank=[{metric,unit,currency?,order:"desc"|"asc",weight:"1"}]`; веса положительные десятичные строки. Отсутствующая ранжирующая метрика также даёт отказ.

Места нормируются в диапазон 0–1 с одинаковой средней оценкой равных значений; один кандидат получает 1. Итог — взвешенное среднее этих мест. Список не порождает целевые веса портфеля. Пример искусственный и не является набором инвестиционных критериев пользователя.
