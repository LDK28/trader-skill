# Контракт общего риск-пакета

Схема `schema_version: 1`: `account_id`, `execution_enabled: false`, `daily_risk` и хотя бы один из `buy_plan`/`sell_plan`. Числа денег — десятичные строки, количество лотов — целые JSON-числа. Подробные схемы вложенных планов описаны в `cash_guard.py`, `sell_guard.py`, `daily_loss.py` навыка-компаньона. Искусственный полный пример — [example.json](example.json).

Дополнительные требования к каждому предложению:

- `price_unit: "settlement_currency"`, `currency` — строчный код валюты расчётов. Для облигаций процентную котировку сначала переводит проверенный нормализатор; сырой `pt` не принимается. `limit_price` — чистая денежная цена за единицу, НКД находится отдельно в полной оценке.
- `instrument.lot_size` — положительное целое, `instrument.price_step` — денежный шаг в тех же единицах, что цена. UID и `quote.instrument_uid` совпадают.
- Для BUY `estimate.binding` точно равен `{account_id, instrument_uid, lots, limit_price, side:"BUY"}`. `principal` не может быть меньше цены × лотов × размера лота.
- Для BUY `own_funds_limit` содержит те же счёт, UID, цену, свежие `as_of`/`expires_at`, `source: "buy_limits"`, `verified:true` и `max_lots`. Сумма лотов всех покупок одного UID не превышает минимальный подтверждённый лимит. `buyMarginLimits` не принимается.
- Повторяющийся UID имеет единые тикер, режим торгов, лотность, денежный шаг, валюту, вид и способ финансирования. Один брокерский `ticker_class_code` не может соответствовать разным UID.
- Дневная база соответствует московской дате расчёта. Пополнения и выводы учитываются отдельно. Текущий `daily_risk.snapshot` обязательно содержит `as_of`/`expires_at`, действителен не дольше 60 секунд с наблюдения и отличается от времени каждого расчётного снимка BUY/SELL максимум на пять секунд. Это согласование наблюдений, а не доказательство атомарного снимка API.

Опциональный объект `limits` поддерживает: `blocked_uids`, `recorded_client_ids`, `orders_already_recorded_today`, `max_orders_per_day`, `amount_currency` с `min_order_amount`/`max_order_amount` для полной стоимости BUY; либо `max_position_fraction` с подтверждёнными `position_values`, `valuation_currency` и `valuation_as_of`. Концентрация использует `daily_risk.snapshot.current_equity`: валюта оценки совпадает с дневной валютой, время оценки — с `daily_risk.snapshot.as_of`. Опциональный `equity` обязан равняться дневному капиталу. Конвертация разных валют для этой проверки пока не поддерживается. Пропуски не подменяются себестоимостью или бюджетом из конфигурации. Неизвестные поля отклоняются. Продажи не уменьшают расчётную концентрацию покупок до фактической сверки.

Снимки и флаги являются утверждениями вызывающего слоя. Проверка арифметики не является проверкой подлинности брокерского ответа. Скрипт не соединяется с API.
