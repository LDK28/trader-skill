# Работа с репозиторием

- Навык расположен в `skills/trader-tinvest`, тесты — в `tests`.
- После изменения расчётных скриптов запускай `python3 -m unittest discover -s tests -v`. Проверки должны работать без сети, токенов и брокерского счёта.
- Различай инструкции навыка, офлайн-валидаторы и фактическую готовность торговой стратегии. Не заявляй прибыльность или полноту исполнения по результатам арифметических тестов.
- Публикуй только исходники, инструкции и искусственные тестовые данные. Токены, конфигурация MCP, реальные снимки счёта и `policy.local.json` остаются локально.
- Предпочтения владельца для текущей разработки: завершённые изменения можно коммитить и отправлять непосредственно в `main`, без отдельного PR. Это относится к задачам изменения кода; запрос на чтение или ревью сам по себе не требует коммита.
- Реальные инвестиционные операции этот проект сейчас не исполняет. Изменение файлов и публикация в GitHub не являются разрешением менять настройки брокерского счёта или права токена.
