# Публичные раскрытия эмитентов и владельцев

Это российская замена **концепции мониторинга публичных раскрытий** исходного `trader-pelosi`. Она не утверждает существование аналога американского реестра сделок Конгресса в России и не приписывает эмитенту, руководителю или владельцу сделку, которой нет в документе. Исходный US PTR-парсер, сроки STOCK Act и американские диапазоны здесь не применяются.

Прочитай [контракт](references/contract.md), затем:

1. Получи доступные публичные документы и индекс через разрешённый источник либо используй сохранённую нормализацию. Сам CLI не ходит в сеть, не обходит авторизацию и не читает личные счета. Название, ID эмитента и URL обязательны; без первоисточника не создавай сообщения о якобы найденном раскрытии.
2. Отдели время публикации от даты события. Неизвестная дата события остаётся `null`. Публикация может описывать будущую дату; отрицательный календарный лаг не объявляется просрочкой. Срок 45 дней исходного американского модуля не переносится на РФ.
3. Сохрани точный смысл документа: изменение доли, уведомление, существенный факт и подтверждённая сделка — разные события. Диапазон суммы остаётся диапазоном; среднее не является фактической ценой или размером сделки. Имена участников используй только в опубликованном контексте документа. Не дополняй их частными сведениями.
4. Для просмотра применяй фильтр эмитента/публично названного участника. Для новых сообщений загрузи локальный seen-state. Одинаковое содержимое повторно не показывается, исправление того же ID возвращается как `UPDATED`. Совпавший ID с противоречивым содержимым в одном индексе блокирует обработку.
5. Запись состояния требует явного `--write-state`; по умолчанию это только расчёт. Возвращаемая `next_state` содержит отпечатки показанных версий. Покажи источник, дату публикации, дату события, вид сообщения и пробелы. Скрипт не проверяет подлинность документов и полноту всех раскрытий страны.

Из корня репозитория:

```bash
python3 skills/trader-pelosi/scripts/disclosures.py index skills/trader-pelosi/examples/disclosures.synthetic.json
python3 skills/trader-pelosi/scripts/disclosures.py new skills/trader-pelosi/examples/disclosures.synthetic.json --state .local/disclosures-seen.json --write-state
```

Вторая команда сохраняет только локальное состояние. Реальные захваты и state не публикуются. Пример искусственный и не сообщает событий реальных компаний. Для напоминаний нужно отдельно согласованное расписание; наличие навыка не запускает мониторинг.

[Банк России описывает](https://www.cbr.ru/issuers_corporate/regulation_supervision_corp_relations_disclosure/) регулирование раскрытия эмитентов и обязанностей участников корпоративных отношений; страница обновлена 27.08.2026, сверена 09.11.2026. Это основание выбора предмета мониторинга, а не гарантия открытости всех документов. Раскрытия не являются прогнозом доходности или торговым поручением.
