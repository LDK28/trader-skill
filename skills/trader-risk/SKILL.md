# Риск-контроль Т-Инвестиций

Используй для проверки подготовленных предложений, а не для выбора стратегии. Требуется установленный рядом навык `trader-tinvest`; его модули выполняют точные денежные проверки. Для пользователя ChatGPT без среды Python объясни расчёт и запроси доступную среду; не изображай запуск кода.

1. Получи единый пакет по [контракту](references/contract.md). Только явно нормализованные данные с источником, временем и точной идентичностью счёта/инструмента. Не выставляй `verified=true` по предположению.
2. Сопоставь пользовательские ограничения, дневную базу и внешние денежные потоки. Пример с порогом 50% не означает согласия другого пользователя на такой риск. Не используй кредитные лимиты или ожидаемые продажи в бюджете покупок.
3. Запусти `python3 scripts/check.py INPUT.json`. Для воспроизводимого искусственного примера допустим `--as-of 2026-01-12T07:00:00Z`; это офлайн-повтор, не проверка текущего счёта.
4. Покажи отдельные результаты дневного порога, бюджета BUY и количества SELL, а также ограничения пакета. Не замалчивай пропущенные проверки комиссий/стоимости продаж. Неполные данные, несовпадающая привязка оценки, повторный расход лимита и неизвестные поля ограничений блокируют пакет.

`PASS_OFFLINE` означает только прохождение расчётных проверок на предоставленных входах. Он не резервирует деньги, не подтверждает подлинность источника и не разрешает исполнение. Никаких брокерских операций, изменения прав или автоматического снятия ограничений.
