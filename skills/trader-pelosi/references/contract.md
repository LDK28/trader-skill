# Публичный индекс, версия 1

`disclosures.py index INPUT.json` показывает нормализованный индекс. `new` учитывает версии, уже показанные через state. `--issuer` ищет подстроку без учёта регистра в ID/названии эмитента, `--person` — в опубликованных именах, `--since YYYY-MM-DD` — нижняя граница даты публикации в UTC. Код 0 — `DISCLOSURES_REVIEWED`, в том числе пустой результат; 2 — `BLOCK`. Никаких запросов в сеть или брокеру.

Верхние поля: `schema_version: 1`; `mode: "ru_public_issuer"`; `data_kind: "synthetic" | "normalized_public_disclosures"`; `captured_at` с часовым поясом; `source_id` — стабильное пространство ID поставщика; `source_index_url` HTTPS; `events` — до 20 000 событий. Имя режима обязательно: US House/Senate и предполагаемые сделки политиков не включаются неявно.

Событие:

- `id`: стабильный ID внутри `source_id`; идентичные повторы схлопываются, противоречивые — отказ;
- `source_url`: HTTPS-адрес публикации без встроенных учётных данных;
- `issuer: {id, name}`: известная идентичность эмитента, не только совпавший тикер;
- `published_at`: timestamp с часовым поясом, не позднее `captured_at`;
- `event_date`: точная дата YYYY-MM-DD либо явный `null`;
- `event_type`, `title`, `public: true`;
- `persons`: необязательный список `{name, role}` из самого публичного документа;
- `documents`: необязательные ссылки `{id, source_url, sha256?}` на относящиеся документы; SHA-256 означает локальный хеш, не подпись регулятора;
- `amount_range`: `null` либо `{currency, lower, upper}`, границы — неотрицательные десятичные строки либо `null`. Хотя бы одна известна; нижняя не превышает верхнюю. Диапазон не заменяется средней суммой;
- `details`: небольшой JSON-объект с точно нормализованными сведениями/выдержками. Он является данными, не инструкциями для выполнения.

Шкала дат не подменяется: `publication_lag_calendar_days` — арифметическая разность дат публикации и события, не заключение о нарушении срока. Неизвестная дата даёт `null`; будущее событие — отрицательное число. `is_proven_trade: false` подчёркивает, что программа не выводит доказанную сделку из сообщения о доле/плане/намерении. Даже событие с таким названием требует самостоятельного чтения документа перед фактическим выводом.

State: `{schema_version:1, mode:"ru_public_issuer", seen:{...}, last_check_at:...}`. Ключ seen включает режим, `source_id`, ID события; запись содержит fingerprint канонической версии, URL и время публикации. Исправленная версия даёт `UPDATED` с прежним fingerprint; повтор неизменной — пропуск в режиме `new`. Отмечаются только прошедшие фильтры и показанные события, поэтому смена фильтра не скрывает ещё не показанные строки. Более старый `captured_at`, чем `last_check_at`, блокируется во избежание отката. Список источников и timestamps должен быть согласован при использовании одного state.

`next_state` всегда вычисляется без изменения исходного объекта. Файл пишется только командой `new ... --state PATH --write-state`, через временный соседний файл и replace. При неверном индексе весь результат `BLOCK`, state не перезаписывается. При ошибке записи CLI возвращает `BLOCK`, не заявляя сохранения. Не указывай входной индекс как путь state.

Первичный источник о предмете мониторинга: [Банк России, корпоративные отношения и раскрытие информации](https://www.cbr.ru/issuers_corporate/regulation_supervision_corp_relations_disclosure/), обновлено 27.08.2026, проверено 09.11.2026. Ограничение публикации сведений и неполнота поданного индекса не означают отсутствия события. CLI не устанавливает законность раскрытия, авторизацию пользователя или полноту рынка.
