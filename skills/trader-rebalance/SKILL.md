# Отклонение от целевого портфеля

Этот модуль сохраняет проверку дрейфа, резерв денег, предел доли, минимальную/максимальную величину сделки и обработку позиций вне целей из исходного Rebalancer. Он создаёт аналитические предложения. Цена портфеля, цена заявки и доходность — разные величины; не заменяй оценку позиции универсальным произведением количества на биржевую цену облигации или производного инструмента.

Требуются Python 3.9+, sibling `trader-tinvest` и sibling `trader-budget`. Запуск по найденной папке навыка:

```bash
python3 /путь/к/trader-rebalance/rebalance.py /путь/к/input.json --output /путь/к/rebalance-result.json
```

Искусственный пример — [references/example.json](references/example.json).

## Контракт

Основа входа совпадает с trader-budget: `account_id`, `currency`, `as_of`, `own_cash`, `targets`, `instruments` и `rules`. Денежные значения и доли — строки. Оценки всех позиций должны быть уже приведены к **одной явно выбранной валюте** по документированному источнику; модуль сам не конвертирует валюты и не выдаёт историю за текущие цены.

Дополнительные поля:

- `positions`: `{uid, currency, units, free_units, value, sell_max_lots}`. `units` — количество бумаг, не лотов; `free_units` исключает блокировки. `value` — предоставленная нормализатором оценка всей позиции в валюте портфеля. `sell_max_lots` — подтверждённый целый неотрицательный предел продажи для этого инструмента/счёта. При его отсутствии нужная продажа отмечается как непроверенная и не выводится предложением.
- `band_fraction`: доля от стоимости всего портфеля; `"0.05"` означает **5 процентных пунктов**, а не 5% от целевой доли. Значение задаётся явно.
- `sell_untracked`: по умолчанию false. Позиции вне целей остаются в отчёте и оценке портфеля; без этого явного параметра продажи по ним не предлагаются.

Стоимость портфеля — текущие собственные деньги плюс предоставленные оценки всех позиций. Из неё рассчитываются резерв и ограниченные целевые величины. При превышении полосы требуется движение к целевому значению полными лотами. Продажи ограничены одновременно отклонением, свободными собственными бумагами, размером лота, `sell_max_lots` и максимальным размером предложения. Сумма оценочных издержек берётся из явной модели trader-budget.

**BUY использует только имеющиеся сейчас собственные деньги сверх резерва.** Предложения SELL могут отображаться раньше BUY, но их ожидаемая выручка никогда не увеличивает бюджет покупок. После фактического внешнего изменения портфеля нужен новый снимок и новый расчёт. Если счёт пока состоит из денег, это первоначальное распределение, а не восстановление прежних долей.

В результате `drift` показывает фактическую/целевую долю и отклонение; `proposals` содержит аналитические BUY/SELL, а `notes` — пропуски из-за лотов, блокировок и отсутствия данных. Свежие брокерские оценки и отдельные проверки BUY/SELL в trader-risk остаются обязательной следующей стадией; модуль не исполняет сделки и не подтверждает прибыльность.
