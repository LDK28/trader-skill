# Вход и состояние

`as_of` — ISO 8601 с часовым поясом, `hours` — целое окно поиска (по умолчанию 48). Будущие новости отклоняются. `watchlist` содержит `{uid,class_code,ticker?}`.

Варианты источников можно смешивать:

- `mcp_news`: сохранённый объект `{items,hasNext?,nextCursor?}`. Поддерживаются настоящие поля MCP: `id,title,source,ts,summary,content,priority,instrumentId:[{instrument:{instrumentUid,classCode,ticker}}]`.
- `items`: нормализованные `{id?,title,source,published_at,url?,summary?,content?,instruments:[{uid,class_code,ticker?}]}`.
- `feeds`: `{source,xml,instruments?}` или `{source,path,instruments?}`. `path` — явно предоставленный локальный RSS/Atom-файл; относительный путь считается от рабочего каталога. Ссылки из XML не загружаются. DTD/entities запрещены.

Новость идентифицируется канонической ссылкой без UTM/фрагмента, затем парой источник/ID, затем текстом/временем. Это эвристика идентичности публикации, а не проверка истинности. При дублях объединяются точные UID-ссылки; при разных временах сохраняется более поздний материал.

`state={seen:{key:last_shown_at},last_as_of}`. Передавай состояние между запусками; прошлый `as_of` относительно состояния запрещён. Сохраняемый `RESULT.json` содержит состояние внутри поля `state`. Статья с тем же ID повторно не показывается в течение срока хранения; для повторного чтения изменений используй `show_seen`.

`more_pages_unread=true` означает неполноту поданного MCP-материала. Тематические теги основаны на словах и не являются классификацией юридического или финансового факта. Все примеры искусственные.
