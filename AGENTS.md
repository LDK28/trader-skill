# Работа с репозиторием

- Пакет: 11 тематических навыков `skills/trader-*` и координатор `skills/trader-tinvest`, всего 12 соседних папок. Контракты этапа — в `docs/porting-contract.md`, карта покрытия — в `docs/migration-status.md`.
- Общие офлайн-помощники и денежные проверки находятся в `skills/trader-tinvest/scripts`. Сохраняй соседское размещение всех навыков и проверяй зависимости при упаковке. Не копируй общие скрипты в независимые несовместимые версии.
- После изменения расчётных скриптов запускай `python3 -m unittest discover -s tests -v`. Проверки должны работать без сети, токенов и брокерского счёта. CLI и ссылки на примеры должны соответствовать реальным путям; для воспроизведения старого примера явно используй его время, не выдавая его за текущий снимок.
- Различай инструкции навыков, нормализованные наблюдения, арифметические проверки, черновики и фактическую готовность стратегии. Успешные тесты и `PASS_OFFLINE` не доказывают прибыльность, подлинность источников или право исполнения.
- Текущий перенос выполняется на файлах и искусственных примерах. Проверка живых источников/MCP, работа со счётом и исследование стратегии требуют отдельной поставленной задачи; не запускай их автоматически ради проверки установки.
- Публикуй только исходники, инструкции и искусственные тестовые данные. Токены, конфигурация MCP, реальные снимки/история счёта, raw-захваты, результаты рыночных исследований, журналы и `policy.local.json` остаются локально. Публичный `policy.json` — пример, не личные настройки владельца и не согласие нового пользователя.
- Обновляя README или карту переноса, описывай одновременно рабочую офлайн-функцию и неподтверждённую интеграцию. Не обещай публикацию в каталоге, импорт ZIP любым клиентом или перенос авторизации вместе с навыками.
- Предпочтение владельца для задач изменения кода с разрешённой публикацией — отправлять завершённые изменения непосредственно в `main`, без отдельного PR. Запрос чтения или ревью сам по себе не требует коммита; отдельное указание не коммитить имеет приоритет.
- Реальные инвестиционные операции проект не исполняет. Изменение файлов, установка навыков и публикация GitHub не являются разрешением менять настройки счёта или права токена.
