# Контракт ценовой проверки

`{as_of,max_quote_age_seconds?,rules:[...],quotes:[...],state?,exchange_schedules?}`. Все времена — ISO 8601 с часовым поясом. Вывод также содержит `as_of_msk` (+03:00). Срок свежести по умолчанию 900 секунд; это настройка наблюдения, не гарантия исполнимой цены.

Котировка: `{uid,class_code,currency,price:"101",as_of}`. Числа — конечные десятичные строки. Будущие, просроченные, повторные и запоздалые котировки не порождают событие. Две разные цены для одного инструмента в одно время — ошибка входа.

Правило цены: `{id,uid,class_code,currency,type,price?,pct?,reference_price?,direction?,rearm?,cooldown_seconds?,fire_on_initial?,market_hours_only?,exchange?}`.

- `type`: `above`, `below`, `stop` (=below), `target` (=above), `pct_move`.
- `above/below`: цена `price`; граница включительна.
- `pct_move`: положительный `pct`, положительный фиксированный `reference_price`, `direction=up|down|either`. База задаётся явно, не угадывается по цене открытия.
- По умолчанию `fire_on_initial=true`: первое наблюдение на нужной стороне даёт `condition_observed`; после противоположного наблюдения — `crossing`.
- По умолчанию `rearm=false`: событие однократное. При `true` противоположное наблюдение вновь взводит правило. Пересечение во время cooldown пропускается, а не откладывается; новое событие требует нового перехода с противоположной стороны.
- `market_hours_only=true` требует подтверждённого открытого сеанса. Неизвестное расписание не считается открытым.

Правило открытия: `{id,type:"opening_bell",exchange,cooldown_seconds?}`. Событие однократно для каждого переданного сеанса; повторные проверки не повторяют его.

`exchange_schedules[exchange]={coverage_start,coverage_end,intervals:[{id?,start,end}]}`. Покрытие полуоткрытое `[start,end)`; интервалы внутри покрытия не должны перекрываться. Пустые интервалы при известном покрытии означают закрытый период. Вне покрытия — `UNKNOWN`.

Состояние хранит времена и значения последних принятых котировок, отпечатки правил и моменты событий. Повторный запуск требует `state` из предыдущего вывода. Чужое или вручную изменённое состояние не является независимым свидетельством прошлого наблюдения. Пример искусственный, а не реальное расписание биржи.
